
# **Praktikum Git dasar** 

🎯 **Tujuan**
- Memahami alur git.
- Tahu beda edit vs staging vs commit.
- Tidak takut pakai Git lagi.



## **Langkah - langkah**


- Bagian 1 Membuat Repositori Gits.<br>
disini kita membuat sebuah direktori atau sebuah folder dan masuk ke folder tersebut,
lalu kita menggunakan perintah **git init** yang berfungsi untuk merubah folder menjadi repositori git

- Bagian 2 membuat file belum masuk ke staging area.<br>
disini saya membuat file txt namun tanpa menggunakan perintah **git add**.

- Bagian 3 Membuat File masuk ke staging area.<br>
disini kita menggunakan perintah **git add** untuk membuat file txt masuk ke staging area.

- Bagian 4 Membuat commit<br>
disini Fungsi dari **git commit -m** ialah untuk menyimpan dan memberikan catatan perubahan apa saja
lalu kita menggunakan perintah git add untuk melihat apakah file sudah masuk ke staging area.

- Bagian 5 Membuat sejarah commit.<br>
disini kita menggunakan commmand **git log** untuk melihat sejarah commit dari waktu ke waktu.

- Bagian 6 Menambahkan teks ke file <br>
disini saya menambahkan teks ke file namun belum di commit.

- Bagian 7 Membuat Commit kedua <br>
disini saya mencoba melihat bagaimana jika saya membuat commit ke 2

- Bagian 8 Membuat Branch(cabang)<br>
disini saya membuat sebuah branch dengan perintah **git branch _nama branch_** dan mencoba mencari tahu perbedaan antara branch main dengan branch lain

- Bagian 9 Membuat Merge<br>
disini saya menggabungkan 2 branch dengan mennggunakan perintah **git merge _nama branch_**



## **Note**


*sebelum membuat commit Pastikan sudah membuat git config username contoh **git config --global user.name _"namamu"_**
